# Valentine's Day Proposal Page 💕

A beautiful, interactive Valentine's Day proposal page built with Next.js, React, and Tailwind CSS.

## Features

- 🎨 **Beautiful UI** with gradient backgrounds and animations
- 📸 **Image Gallery** with Instagram-style carousel navigation
- 💬 **Interactive Buttons** with fun reactions
- 🎉 **Confetti Animation** on success
- 💗 **Floating Hearts** animations throughout the page
- 📱 **Fully Responsive** design
- ✨ **Smooth Animations** and transitions

## How It Works

1. **Gallery Section** - Browse through romantic images using next/previous buttons
2. **Interactive Buttons** - Click YES or NO to respond to the proposal
3. **Fun Reactions** - 
   - YES button grows larger as NO is clicked
   - NO button shrinks and becomes harder to click
   - Playful messages appear encouraging a YES
4. **Success Page** - Confetti celebration and love message when YES is clicked

## Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the proposal page.

### Customization

To add your own images:
1. Place images in the `public` folder
2. Update the `galleryImages` array in `app/page.tsx` with your image paths

### Build for Production

```bash
npm run build
npm start
```

## Tech Stack

- **Next.js 16** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Canvas Confetti** - Celebration effects
- **Next.js Image** - Optimized images
